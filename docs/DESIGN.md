# DESIGN — NOMAD 데스크톱 디자인 브리프 (task-006)

> 정답 소스는 [`design/tokens/tokens.css`](../design/tokens/tokens.css) 하나다. 값 표 사본은 [`design/tokens/TOKENS.md`](../design/tokens/TOKENS.md)(`design-preview --md` 생성), 미리보기는 [`design/tokens/preview.html`](../design/tokens/preview.html). 이 문서는 브리프·패턴 설명만 쓴다.

## 1. 브리프
- 대상: 로컬 폴더의 Markdown·PDF를 찾고 관계로 파악하는 개인 사용자(Windows 데스크톱 앱, Electron).
- 주된 일: 자료 검색 → 관계 그래프에서 맥락 파악 → Claude Code 스킬 실행 전 동의.
- 분위기 3단어: 차분함 · 정확함 · 투명함(외부 처리와 샘플 데이터를 숨기지 않는다).
- 피할 것: 색만으로 의미 전달, 장식용 그라데이션, 외부 처리·샘플을 가리는 작은 글씨, 그래프 위 과한 애니메이션.

## 2. 반응형 (데스크톱 우선)
- 구간: 모바일 ~767 / 태블릿 768~1199 / 데스크톱 1200~ (창 폭 기준).
- 좁은 창 기준(정의): **창 최소 폭 720px에서 핵심 플로우가 동작한다.** 핵심 플로우 = S-02 대시보드 → S-03 검색·문서 미리보기 → S-05 동의 후 실행 → S-07 결과 확인. 720px에서는 사이드바가 아이콘 레일로 접히고, 그래프는 목록 보기로 자동 전환되며, 페이지 가로 스크롤은 없고 표·코드 블록만 카드 안에서 스크롤한다. 720px 미만은 보장 범위 밖이며 핵심 버튼이 잘리지 않는 것만 확인한다.
- 모바일 전용 레이아웃은 범위 밖.

### 글자 크기 표 (필수, 토큰 값과 같음)
| 토큰 | 모바일 ~767 | 태블릿 768~1199 | 데스크톱 1200~ |
|---|---|---|---|
| `--text-display` | 28px | 36px | 48px |
| `--text-h1` | 24px | 28px | 34px |
| `--text-h2` | 20px | 22px | 26px |
| `--text-body` | 15px | 16px | 16px |
| `--text-caption` | 12px | 13px | 13px |

- 서체: 한국어 본문 Pretendard Variable. 숫자·금액·경로·실행 로그는 `--font-mono`(JetBrains Mono 또는 Cascadia Mono).
- 사이드바 폭도 구간별 토큰(`--layout-sidebar`: 220 / 200 / 220px)으로 둔다.
- 추가 토큰(task-020, 값은 `design/tokens/tokens.css`): `--layout-rail`(56px, 767px 이하 사이드바 아이콘 레일) · `--layout-search-min`(200px) · `--layout-result-min`(280px)·`--layout-result-min-narrow`(240px) · `--layout-preview-max-height`(40vh) · `--size-skeleton-height`(64px) · `--border-width`(1px).
- Fluent 컨트롤(Input·Select·Button·Tab) 글자 크기는 테마 오버라이드(`fontSizeBase300`→`--text-body`, `fontSizeBase200`→`--text-caption`)로 3구간 토큰을 따른다.

## 3. 색 (라이트·다크 모두 같은 이름)
- 본문 글자·버튼 글자: WCAG AA 4.5:1 이상. 아이콘·입력 경계: 3:1 이상.
- 검사 명령: `design-preview design/tokens/tokens.css --check` (전체 표는 작업 로그 `contrast.txt`). 요약:
  - 라이트: 본문 `--color-text`/bg 17.96:1, 음소거 `--color-text-muted`/bg 6.13:1, 버튼 글자 최저 4.84:1(`domain-2`), 입력 경계 `--color-input`/bg 3.34:1.
  - 다크: 본문 16.56:1, 음소거 7.34:1, 버튼 글자 최저 6.16:1, 입력 경계 3.68:1.
  - 모든 검사 쌍 통과(`design-preview --check`). 분야 색의 그래프 배경 대비(3:1)는 현재 검사 도구가 짝을 찾지 못해 **미계산**(§4 사람 확인).

## 4. 분야(도메인) 팔레트 — 색 외 단서 포함
분야는 최상위 태그 또는 루트 폴더 단위다(ADR-0003). 색이 같아도 구분되도록 **색 + 도형 키 + 목록 글자**를 함께 쓴다.

| 분야 | 라이트 토큰 | 다크 토큰 | 도형 키 (그래프 노드·칩 앞) | 패턴 (선·테두리) |
|---|---|---|---|---|
| 1 | `--color-domain-1` 파랑 | `--color-domain-1` (밝은 값) | ● 원 | 실선 |
| 2 | `--color-domain-2` 청록 | (밝은 값) | ▲ 삼각 | 실선 |
| 3 | `--color-domain-3` 갈색 | (밝은 값) | ■ 사각 | 실선 |
| 4 | `--color-domain-4` 자주 | (밝은 값) | ◆ 마름모 | 실선 |
| 5 | `--color-domain-5` 초록 | (밝은 값) | ✚ 십자 | 실선 |
| 6 | `--color-domain-6` 보라 | (밝은 값) | ★ 별 | 실선 |
| 태그 노드 | — | — | 작은 원 + `#` 접두 | 점선 테두리 |
| 없는 문서 | `--color-graph-missing` | 같은 이름 | 빈 원 | 점선 테두리 + "없는 문서" 글자 |

- 분야 6개를 넘으면 새 분야는 "기타"로 묶는다(7색 금지: 구분 불가).
- 칩·범례·목록 모두 "도형 키 + 이름 + 색"을 같이 쓴다. 색 대비가 모자라도 도형과 글자로 구분된다.
- 색 구분 불가 사용자(색각 이상)는 도형 키로 식별한다. 이 규칙은 색 값을 바꿔도 유지한다.

## 5. 3D 그래프 · 2D · 목록 전환 (S-03)
- 세 보기는 같은 부분 그래프 데이터(A-05)를 공유하고, 필터·선택 상태를 전환해도 유지한다.
- 기본 보기: 3D 그래프. 기술 검증(task-017) 전에는 렌더러를 확정하지 않는다. 이 문서는 패턴만 정한다.
- 전환 규칙:
  - 보기 전환 컨트롤은 탭 3개(3D 그래프 · 2D 그래프 · 목록), 키보드로 이동 가능, 현재 보기는 `aria-selected` + 밑줄 + 글자로 표시.
  - 3D 실패(WebGL 오류·저사양·"동작 감소" 설정): 자동으로 2D 그래프로 내려가고 상단에 한 줄 안내 + "다시 시도" 버튼. 2D도 실패하면 목록.
  - 목록 보기는 항상 사용 가능한 최종 대체다. 그래프와 같은 정렬·선택·키보드 이동을 따른다.
- 그래프 조작: 노드 클릭 = 선택(우측 미리보기 카드 갱신), 더블 클릭 = 중심 노드 변경, "선택 고정" 버튼 = 선택 노드 위치 고정. 상세 정보는 그래프 밖(우측 카드·목록)에서 읽는다.
- 모션: `prefers-reduced-motion` 또는 앱 설정 "동작 줄이기"이면 회전·흔들림 없이 정적 배치.
- 노드 수 제한: 기본 표시 수를 넘으면 "표시 N / 전체 M" 문구와 "더 보기"를 쓴다.

## 6. 외부 처리 동의 UI (S-05)
- 실행마다 동의한다. 이전 동의나 "기억한 허용"은 외부 처리 동의를 대신하지 않는다(ADR-0006, S-05 문구 그대로).
- 구성 순서: 입력값 → 접근 폴더 → 허용 도구 → 고지 패널 → 동의 체크박스 → 실행 버튼.
- 고지 패널(`--color-notice` 배경, `--color-notice-border` 좌측 굵은 선 4px, ⓘ 아이콘)은 색만으로 강조하지 않는다. 제목 "외부 처리 안내"를 먼저 쓴다.
  - 고지 문구: Claude Code에 설정된 원격 AI 서비스와 앱이 확인 가능한 서비스·계정 정보를 표시한다. 확인할 수 없는 정보는 "확인할 수 없음"으로 표시한다. 승인 폴더 안에서 모델이 실제로 읽을 파일 목록은 미리 확정되지 않을 수 있다고 쓴다.
- 체크박스: 레이블이 "이번 실행의 외부 AI 처리에 동의합니다", 체크 전 실행 버튼은 비활성 + 비활성 이유 한 줄("동의 체크 필요"). 비활성 버튼은 색 외 단서로 점선 테두리와 "비활성" 글자 상태를 쓴다.
- "이 스킬에 이 범위 기억" 탭은 접근 범위만 저장한다. 범위가 넓어지면 다시 묻는다.
- 실행 후 S-07에 같은 동의 시각·서비스 표시를 남긴다.
- 오류: 필수 입력 누락·범위 실패·미동의는 이유를 폼 옆에 텍스트로 쓰고 포커스를 첫 오류 필드로 옮긴다.

## 7. 포커스·움직임·기타
- 포커스 링: `--color-focus`, 두께 `--focus-ring-width`, 바깥 여백 `--focus-ring-offset`. 키보드 포커스는 항상 보인다.
- 그림자는 카드 한 종류(`--shadow-card`)만. 모달도 같은 그림자.
- 샘플 데이터는 `--color-badge-sample` 배지로 실제 자료와 구분한다(S-02).

## 8. 사람 확인 필요 (확정은 사람이 한다)
1. 미리보기 [`design/tokens/preview.html`](../design/tokens/preview.html) 확인: 라이트·다크 값, 글자 크기 3구간.
2. 후보 비교(에이전트 제안, 미확정): 본문 색 `#15171a`(현재) vs 더 진한 `#0b0d10`; 분야 팔레트는 현재 6색 유지 vs 채도 낮춘 세트.
3. 분야 색의 그래프 배경 대비(3:1): 검사 도구 미지원. 확정 전 스크립트 또는 사람이 확인.
4. 토큰 형식: 현재 init 시작본의 Tailwind CSS v4 `@theme` 형식. 실제 UI는 Fluent UI v9 + Electron이다(ADR-0005). 토큰을 Fluent `webLightTheme`/`webDarkTheme` 오버라이드 객체로 옮길지, CSS 변수로 둘지 결정 필요(task-007 전).
5. 3D 그래프 렌더러 선택(task-017 결과 후). 이 문서의 3D 패턴은 렌더러와 무관하게 유지.
6. 720px 좁은 창 기준은 제안이다. 사람이 확정.
