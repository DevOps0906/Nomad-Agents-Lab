> 형식: ~/.claude/skills/ux-patterns/SKILL.md 2절. 표를 채우면 `plan2spec`이 구조도·와이어프레임·필수 구조 검사를 만든다.

## 그래프 접근성·성능 (S-03)
- 3D 그래프를 제공하되 검색·필터·중심 노드 기준의 제한된 이웃만 가져온다. 상한은 W0 task-017 벤치마크 후 확정한다.
- 2D와 목록은 3D와 동등한 검색·선택·미리보기·관련 노드 탐색 경로다. 키보드 경로: 검색 결과(위/아래·Enter) → 미리보기 → 관련 노드 목록(연결 이유 표시) → Enter로 선택. 캔버스 없이 핵심 흐름을 완주할 수 있어야 한다.
- 동작 감소(설정 또는 `prefers-reduced-motion`)면 자동 회전·강제 움직임을 끄고 정지 레이아웃을 제공한다. 3D/WebGL 미지원·오류·성능 저하 시 2D/목록으로 전환한다.
- 선택 노드는 윤곽선·라벨·미리보기로 함께 표시한다. 직접 연결(manual)과 추출 관계는 선 모양으로도 구분한다.
