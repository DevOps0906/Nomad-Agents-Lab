# ADR-0003 Second Brain 그래프: 문서=노드, 링크·태그=관계

- 상태: 채택 (2026-11-03, 사용자 선택)
- 맥락: 원 기획에 노드·관계를 만드는 방법이 정의되지 않았다.

## 선택
결정적 로컬 추출만 사용한다(외부 전송 0, AI 호출 0).
| 관계 종류 | 출처 | 대상 |
|---|---|---|
| `link` | `[[위키링크]]`, Markdown 상대 링크 | Markdown → 문서 |
| `tag` | frontmatter `tags`, 본문 `#태그` | 문서 ↔ 태그 노드 |
| `folder` | 같은 폴더(옵션, 기본 끔) | 문서 ↔ 폴더 노드 |
| `manual` | 사용자가 앱에서 직접 연결 | 문서 ↔ 문서 |
- PDF는 텍스트를 추출해 검색에 넣는다. 관계는 `manual`·`folder`만 가진다.
- 분야 색상 = 최상위 태그 또는 루트 폴더. 사용자가 바꿀 수 있다.
- 깨진 링크는 "없는 문서" 노드로 표시한다.

## 대안
로컬 임베딩 유사도·AI 개념 추출은 2차 이후 재검토한다(품질은 좋아지지만 비용·비결정성·전송이 생긴다).

## 결과
그래프는 재현 가능하고 "왜 연결됐나"를 항상 설명할 수 있다. 태그·링크가 적은 자료에서는 그래프가 성기다 → 빈 상태 안내에 반영한다.
