# ADR-0004 이전 MVP 범위: 2D 수직 슬라이스

- 상태: 대체됨 (2026-11-03, [ADR-0006](0006-balanced-mvp-scope.md))
- 맥락: 당시 제안된 범위 결정의 이력이다. 2D 그래프만 1차에 넣고 3D를 2차로 미루는 안은 현재 승인된 범위가 아니다. 2026-11-03 사용자 승인 균형안은 ADR-0006을 따른다.

## 이전 제안
| 차수 | 포함 |
|---|---|
| 1차 MVP | 첫 실행 점검(Claude Code·데이터 폴더) → 로컬 폴더 연결·색인 → 검색 → **2D** 그래프·문서 미리보기 → 스킬 목록·실행(승인) → 실행 기록 → 대시보드 → 최소 설정 |
| 2차 | 3D 그래프 뷰(2D와 같은 데이터), 루틴 예약(앱 실행 중·트레이 상주), MCP 연결 관리, 가져오기·내보내기 |
| 3차 | Google Drive, 앱 종료 중 루틴(Windows 작업 스케줄러), 스킬 편집기, 임베딩 관계 |

## 이전 승인 피로 대책
- 실행 승인은 "이번 한 번" / "이 스킬에 대해 이 범위를 기억"으로 고를 수 있다. 기억한 허용은 설정 > 권한에서 보고 해제한다.
- 범위가 넓어지면(새 폴더·새 도구) 기억한 허용과 상관없이 다시 묻는다.

## 이력
이 ADR의 과거 제안은 새 범위 기준으로 사용하지 않는다. 현재 범위·승인 정책은 [ADR-0006](0006-balanced-mvp-scope.md), PRD, UX 명세를 정본으로 삼는다.
