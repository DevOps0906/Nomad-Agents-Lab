# ADR-0002 스킬 형식: SKILL.md 호환

- 상태: 채택 (2026-11-03, 사용자 선택)
- 맥락: 스킬은 SSR+ 4영역 중 하나인데 원 기획에 데이터 구조가 없었다.

## 선택
스킬 = **Claude Skills 표준 폴더**(`<스킬명>/SKILL.md`, frontmatter `name`·`description` + 본문). 앱은 파일을 원본으로 두고 SQLite에는 색인·실행 기록만 저장한다.
- 읽는 위치: 사용자 `~/.claude/skills/`, 앱이 관리하는 스킬 폴더(설정에서 지정). 둘 다 읽기 전용으로 시작한다.
- 앱 전용 확장은 frontmatter의 `ssr:` 키 아래에만 둔다(Claude는 무시한다). 예: `ssr.inputs`(입력 필드·필수 여부), `ssr.reads`(필요 폴더), `ssr.tools`(필요 도구).
- `ssr:`가 없는 스킬도 실행할 수 있다. 입력은 자유 텍스트 1칸, 권한은 실행 승인 때 지정한다.
- 실행은 ADR-0001 엔진에 "스킬 `<name>`을 이 입력으로 수행"하도록 프롬프트를 넘긴다.

## 대안
앱 전용 YAML/JSON: 기존 스킬과 호환되지 않는다. 둘 다 지원: 이중 관리.

## 결과
기존 스킬을 바로 쓸 수 있다. 스킬 편집기는 후속(ADR-0006)으로 미루고, MVP는 "폴더 열기"만 제공한다.
