# 05 데이터 모델 — SSR+ (1차 MVP, 로컬 SQLite)

> ERD: [`diagrams/erd.mmd`](diagrams/erd.mmd) — `sql2erd app/migrations -o docs/diagrams/erd.mmd`로 생성(손으로 그리지 않음). 스키마 정본: `app/migrations/*.sql`
> 테이블: DB 안 일반 테이블 11개 + FTS5 가상 테이블 1개(`doc_fts`). `boot_config`는 DB 밖 JSON 파일.
> DB 파일은 S-01에서 고른 데이터 위치 폴더에 1개(`ssr.db`). 그 경로는 DB 밖 부트 설정에 둔다([`02_ARCHITECTURE.md#1`](02_ARCHITECTURE.md)).
> 원본 파일은 복제하지 않는다. 비밀값 컬럼 없음([ADR-0001](adr/0001-ai-engine-claude-code-cli.md)).

| `links` | 문서 간 관계 | `id`, `src_doc_id`→documents, `dst_doc_id`→documents(NULL 허용, 대상 문서 삭제 시 NULL), `dst_raw`(원래 링크 문자열), `dst_key`(정규화 대상 키), `kind`(`link`·`manual`), `created_at` | 로컬 단일 사용자—해당 없음 | `dst_doc_id` NULL 또는 `status`=`deleted` 문서를 가리키는 관계는 그래프에서 "없는 문서" 노드로 취급(ADR-0003, A-05 `totalNodes`에 포함). ## 인덱스·제약 (구현 시)
- 외래 키 강제(`PRAGMA foreign_keys=ON`), WAL 모드, `STRICT` 테이블.
- 시각 컬럼은 ISO 8601 UTC 문자열(예: `2026-11-20T08:00:00.000Z`), 파일 `mtime`은 epoch 밀리초 정수.
- 인덱스: `documents(source_id)`, `links(src_doc_id)`, `links(dst_doc_id)`, `tags(name)`, `runs(started_at)`, `runs(skill_name)`, `grants(skill_name)`.
- 스키마 버전 정본은 `PRAGMA user_version` 하나. 마이그레이션은 `app/migrations/NNNN_name.sql` 순번 파일, **전진 전용**(down 없음). 적용 전 backup API로 백업하고, `user_version`이 앱보다 높으면 열지 않는다.
