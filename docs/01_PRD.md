# 01 PRD — SSR+ 개인 AI 업무 시스템

> 근거: `00_LEAN.md` (결과: **개발 착수 승인, 본인 알파 우선**) · 초기 비전 `.azure/project-plan.md` · 현재 범위 결정 `adr/0006`

## 1. 한 줄 정의
Claude Code를 쓰는 Windows 개인 사용자를 위한 **로컬 우선 데스크톱 앱**: 로컬 지식을 검색·Second Brain 그래프로 탐색하고, 매 실행마다 외부 AI 처리와 자료 접근 범위를 명시적으로 승인해 스킬을 실행하고, 기록을 확인한다.
- 핵심 가치 1개: "AI가 무엇을 읽고 무엇을 했는지 보이는 실행"
- AI 엔진은 사용자 PC의 Claude Code CLI(`adr/0001`). 앱은 AI API를 직접 호출하지 않고 API 키를 저장하지 않지만, CLI가 구성된 원격 AI 서비스와 통신할 수 있다. 로컬 우선은 오프라인을 의미하지 않는다.
- 데스크톱 스택: `adr/0005`(제안, 확정은 Q1).

## 6. 하지 않을 것 · 금지 문구
- 1차에 2차 기능 구현 금지(3장 표 기준). 모바일 우선 앱, 다중 사용자·조직, 공개 마켓플레이스, 클라우드 동기화 기본 제공 금지.
- 앱이 Claude API 등 AI를 직접 호출하거나 API 키를 저장하지 않는다(`adr/0001`).
- Claude Code의 원격 AI 서비스 처리를 "로컬 전용", "완전 오프라인" 또는 "외부 전송 없음"으로 표현하지 않는다. 매 실행별 동의 없이 CLI를 실행하지 않는다.
- 원본 파일 변경 금지: 색인·미리보기·스킬 읽기는 읽기 전용(`adr/0002`, `adr/0003`).
- 승인 없이 사용자 의도를 추측해 파일을 바꾸거나 범위를 넓히는 실행 금지.
- 금지 문구: "자료를 외부로 보내지 않습니다", "완전 오프라인". 대신 "승인한 폴더의 자료가 Claude Code가 설정된 AI 서비스에서 처리될 수 있습니다. 매 실행 전에 범위를 확인하고 동의해야 합니다."라고 고지한다. "모든 파일 형식 지원", "OCR 지원"도 금지.

## 8. 보안·공급망 (비우지 않는다 — 기준: `security-baseline` 스킬)
| 항목 | 값 |
|---|---|
| 보안 레벨 | **L1 저장소**. 설치 파일을 타인에게 배포하는 시점에 L2 상향 여부 재검토 — 팀장 결정 필요(Q8) |
| 고객·판매 대상 | 개인 |
| 배포 형태 | 설치형 Windows 데스크톱 앱(셸은 Electron **제안**, Q1). 서버 없음 |
| 인터넷 노출 면 | 공개 페이지·공개 API·웹훅·관리자·업로드 **없음**. 앱 자체의 텔레메트리·AI API 요청은 없다. 단, 명시 승인 후 Claude Code CLI가 구성된 원격 AI 서비스와 통신하며 스킬·입력·승인 폴더에서 읽은 문서 내용을 처리할 수 있다. 로컬 노출 면: ① renderer→main IPC(A-01~A-17, allowlist) ② 연결 폴더 파일 읽기 ③ Claude Code CLI 자식 프로세스·원격 요청 ④ 사용자 문서 렌더링(신뢰할 수 없는 콘텐츠) ⑤ 실행 중 권한 응답 채널(T-01). 각 면의 위협 메모는 기능 명세에 둔다 |
| 민감 데이터 | 원본 파일: 사용자 폴더에 그대로, 앱 색인은 읽기 전용. Claude Code 실행 시 승인 폴더 안의 어떤 파일이 실제로 읽힐지 사전 확정할 수 없음을 S-05에서 고지하고 매 실행 동의를 받는다. 앱은 파일 본문을 동의 로그에 복제하지 않는다. 메타데이터·색인·실행 기록은 로컬 SQLite(보존 기간 Q6), 자격 증명은 앱 보관 없음 |
| 키·권한 | 앱이 보관하는 키 **없음**(Claude Code 인증은 CLI가 관리). AI 에이전트가 닿는 범위 = 실행마다 승인된 작업 디렉터리 + `--add-dir` 폴더, 도구는 1차 고정(Read·Grep·Glob 기본, Write·Edit는 실행별 출력 폴더 안에서만, Bash·WebFetch·WebSearch는 `--disallowedTools`로 금지), MCP는 1차 사용 안 함(`--strict-mcp-config` + 권한 브리지 외 차단, T-03·Q18). 매 실행의 외부 처리 동의는 기억한 허용과 별개다. 범위 확대 시 재승인([ADR-0006](adr/0006-balanced-mvp-scope.md)) |
| 라이선스 예외 | 없음 |
| 취약점 처리 기한 | 기본값(`vuln-priority.md` 3절) |
