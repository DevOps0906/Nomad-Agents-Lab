# 벤치마킹 — 1차 MVP 핵심 화면

> 형식: ~/.claude/skills/ux-patterns/SKILL.md 3절. 대상 3개 × 핵심 화면 1개.
> 근거: 이번 작성 때 웹·스크린샷을 확인하지 못했다. "반드시 있는 것"은 작성자 기억에 따른 것으로 모두 **미확인**이며, 사람이 공식 문서·실제 화면으로 확인한 뒤 근거 칸을 채운다.

| 제품 | 화면 | 반드시 있는 것 | 우리에게 없는 것 | 채택 여부 | 근거(URL·스크린샷 경로) |
|---|---|---|---|---|---|
| Obsidian | 그래프 뷰 (S-03 대응) | 링크·태그 기반 노드 그래프, 필터(검색어·태그·첨부·고아 노드), 그룹별 색 지정, 표시 설정(노드 크기·선 굵기), 노드 클릭 시 문서 열기, 로컬 그래프(현재 문서 주변만) | 그룹별 색 사용자 지정 UI, 고아 노드 표시 토글, 현재 문서 중심 "로컬 그래프" 모드 | 부분 채택: 관계 종류 필터·분야 색(ADR-0003)은 이미 반영. 로컬 그래프는 "관련 노드 목록"으로 대체, 그래프 모드는 2차 검토 | 미확인 |
| Logseq | 페이지 + 참조 패널 (S-03 미리보기·관련 노드 대응) | 페이지 하단 연결된 참조(backlinks)·연결 안 된 참조, 우측 사이드바에 페이지 열기, 그래프 뷰 | "연결 안 된 참조"(제목이 언급됐지만 링크 안 된 문서) 목록 | 미채택(1차): 결정적 추출만 쓰는 ADR-0003 범위 밖. 2차 후보로 기록 | 미확인 |
| Raycast AI | AI 명령 실행 (S-04·S-05 대응) | 명령 검색 목록, 명령별 입력, 실행 전 확장 권한 확인, 결과 화면에서 후속 작업 | 키보드 전용 빠른 실행(명령 팔레트), 결과에서 바로 후속 명령 | 부분 채택: 검색·상세·실행 준비 구조는 S-04에 반영. 전역 명령 팔레트는 2차 검토 | 미확인 |

## 채택 요약
- 화면 표 `구성`에 이미 반영: 관계 종류 필터·범례(S-03), 관련 노드 목록(연결 이유 표시)(S-03), 스킬 검색·상세 패널·실행 준비(S-04).
- 미채택·보류: 그래프 그룹 색 편집 UI, 연결 안 된 참조, 전역 명령 팔레트 → 사람 판단 후 2차 범위에서 결정.
