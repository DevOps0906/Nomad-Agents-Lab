## 할 것
- 승인된 스택에서 대표 그래프 샘플을 사용해 3D 렌더링·검색/필터·선택·카메라 조작 가능성을 검증한다.
- 대상 Windows 기기·샘플 노드/관계 수·프레임/응답 측정 방식을 기록하고, 측정 결과에 근거해 표시 상한과 성능 합격 기준을 결정한다.
- 2D·목록 대체 경로, 키보드 탐색, 동작 감소, WebGL 미지원·오류 시 동작을 점검한다.
- 확정된 상한·성능 기준·설계 선택을 PRD Q7·Q13, S-03, A-05에 일치시킨다.

## 하지 않을 것
- 제품 앱에 그래프 기능 구현
- 실제 사용자 자료를 스파이크에 복사
- 측정 전 임의의 수치나 성능 달성을 완료로 기록

## 완료 조건 (실행 가능한 확인)
- [ ] 재현 가능한 샘플·기기·측정 결과를 `spikes/brain-graph/`에 기록

- [ ] 2D·목록·접근성·오류 대체 기준이 PRD·UX·IPC에 일치
